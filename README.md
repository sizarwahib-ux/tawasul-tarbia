# المنصة الرقمية لإدارة واستقبال انشغالات قطاع التربية — ولاية تيارت
### People's Democratic Republic of Algeria — Ministry of National Education
### Directorate of Education — Province of Tiaret (14)

---

## 📌 نبذة عن المشروع (About the Project)
منصة ويب متكاملة رسمية ومطابقة لمعايير الرقمنة الإدارية لوزارة التربية الوطنية بالجمهورية الجزائرية الديمقراطية الشعبية، مخصصة لاستقبال، تصنيف، معالجة، ومتابعة انشغالات الأسرة التربوية (أساتذة، إداريين، عمال مهنيين) وكذا أولياء التلاميذ والمواطنين بمديرية التربية لولاية تيارت (14).

---

## ✨ المميزات الرئيسية (Key Features)

1. **إيداع إلكتروني مرن وسهل للانشغالات:**
   - استمارة دقيقة تحدد صفة المعني (مواطن/ولي أمر أو موظف بالقطاع، الرتبة، والمؤسسة التربوية).
   - توجيه آلي للمصلحة المختصة (مصلحة المستخدمين، التنظيم التربوي، نفقات المستخدمين، المالية والوسائل، الدراسة والامتحانات، البرمجة والمتابعة، التكوين والتفتيش، الأمانة العامة، ومدير التربية).
   - إمكانية إرفاق وثائق ثبوتية أو تقارير.

2. **وصل إيداع وبطاقة موعد رسمي قابل للطباعة (A4):**
   - توليد رقم وصل مرجعي فوري (`TR-26-XXXXX`).
   - توليد رقم طابور واستقبال (`Q-XXX`).
   - رمز استجابة سريعة (QR Code) وشريط ترميزي (Barcode) للتحقق الإلكتروني.
   - تأشيرة وختم الاستقبال وتنسيق جاهز للطباعة المباشرة بصيغة A4.

3. **لوحة تحكم إدارية مركزية متقدمة للمصالح (`/admin`):**
   - مؤشرات أداء حية (إجمالي الانشغالات، قيد المعالجة، المواعيد المبرمجة، المعالجة بنجاح، الحالات العاجلة).
   - فلترة متقدمة حسب المصالح التسعة، درجات الأهمية، والحالات.
   - تحديد مواعيد المقابلات الحضورية (اليوم، التوقيت، ورقم الدور).
   - كتابة وإرسال ردود الإدارة الرسمية على الملفات.
   - تصدير كامل السجل الإداري إلى ملف **Excel (XLSX)** منسق من اليمين إلى اليسار (RTL).

4. **فصل كامل لأمان الدخول الإداري عن دخول المرتفقين:**
   - **بوابة دخول المرتفقين (`/login`):** خاصة بالمواطنين والأسرة التربوية لمتابعة انشغالاتهم.
   - **بوابة دخول الإدارة المستقلة (`/admin/login`):** خاصة بالمشرفين ورؤساء المصالح المعتمدين مع إمكانية تعديل اسم المستخدم وكلمة السر بعد الدخول.

5. **مزامنة مركزية كاملة (Full-Stack Sync):**
   - خادم Express مدمج مع تخزين مركزي للبيانات لضمان عمل المنصة ومزامنتها من أي جهاز أو متصفح في الوقت الفعلي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, React Router 7, Lucide Icons.
- **Backend / API:** Node.js, Express, TSX, Vite Middlewares.
- **Data & Export:** JSON File Storage & Persistent Local Cache, SheetJS (`xlsx`).
- **Typography:** خطوط عربية رسمية معتمدة (Cairo & Tajawal).

## 🚀 التشغيل والتثبيت المحلي (Getting Started)

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مدير الحزم `npm` أو `bun` أو `yarn`.

### خطوات التشغيل:
```bash
# 1. استنساخ المشروع
git clone https://github.com/<your-username>/tiaret-education-portal.git

# 2. الدخول إلى مجلد المشروع
cd tiaret-education-portal

# 3. تثبيت الاعتماديات
npm install

# 4. تشغيل الخادم في وضع التطوير (Dev Mode)
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 📂 هيكلة المشروع (Project Structure)

```text
├── data/                  # قاعدة البيانات المركزية والتكوين الإداري
│   ├── concerns.json      # سجل الانشغالات والمواعيد
│   └── admin_config.json  # بيانات اعتماد حساب الإدارة
├── src/
│   ├── api/               # محولات ومصادر واجهة برمجة التطبيقات
│   ├── components/        # المكونات العامة (Header, Footer, Layout, Toaster)
│   ├── lib/               # إدارة المصادقة، التخزين، التصدير، والإعدادات
│   ├── pages/             # صفحات المنصة (الرئيسية، إيداع، انشغالاتي، وصل، الإدارة، الدخول)
│   ├── App.tsx            # موجه التطبيق وتوزيع المسارات
│   └── main.tsx           # نقطة الدخول الرئيسية للتطبيق
├── server.ts              # خادم Express ومسارات API
├── index.html             # الصفحة الأساسية ودعم اللغة العربية RTL
├── package.json           # الحزم والأوامر التشغيلية
└── vite.config.ts         # إعدادات Vite و Tailwind CSS
```
